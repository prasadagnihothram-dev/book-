PAGETURNER ONLINE BOOKSTORE

Files:
- index.html: bookstore page structure and small add-to-bag demo interaction
- style.css: responsive styling

How to run:
1. Extract the ZIP file.
2. Open index.html in a modern web browser.

Notes: Fonts are loaded from Google Fonts when internet is available. The checkout link is a demo mailto link; connect a payment/cart backend for real orders.
